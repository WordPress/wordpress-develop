=== Contributing to Twenty Eleven ===

= Minifying CSS =

Twenty Eleven has a block stylesheet `blocks.css` which is enqueued for block editor support. On a normal production site, when `SCRIPT_DEBUG` is disabled, then the minified version `blocks.min.css` will be enqueued instead. If you make a change to `blocks.css`, you'll need to re-minify the `blocks.min.css` using the built-in npm build tool.

Installation instructions

1. Using a command line interface, go to the "twentyeleven" directory `cd /my-computer/local-wordpress-install/src/wp-content/themes/twentyeleven`.

2. Type `npm install` into the command line, and press the [return] key, to install all Node.js dependencies.

3. The dependencies may take a few minutes to download but once it completes, you're done.

Usage instructions

1. After making a change to the `blocks.css` file, run `npm run build` from within the theme directory to regenerate `blocks.min.css` with your new changes.

2. You can also "watch" the theme directory for CSS changes and re-minify the CSS anytime a change occurs by running: `npm run watch`.
